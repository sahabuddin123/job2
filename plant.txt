==================================================
PLAN AND CHECK - JOB 02: NEWS PORTAL
==================================================

1. PURPOSE AND AUDIENCE
The website is a small dynamic news portal for general readers.

2. FUNCTIONAL REQUIREMENTS
- List news from database
- Add a new news item
- Search news by title
- Provide a JSON API

3. CODING PLAN
The following files and database structure are used:
- Database: daily_city_desk
  - Table: category (category_id, category_name)
  - Table: reporter (reporter_id, full_name)
  - Table: news (news_id, title, description, category_id, reporter_id, published_on) with foreign keys and index on title.
- config.php: Centralized PDO database connection with prepared statements.
- index.php: Main portal displaying dynamic news with title, description, category, and reporter, prepared title search, and JavaScript fetch API display.
- add.php: News entry form with title, description, relational dropdowns (category, reporter), and published date, inserting rows using prepared statements.
- api/news.php: JSON API returning news titles and categories from the database.
- style.css: Modern, readable stylesheet for layouts, cards, and responsiveness.
- images/news-image.jpg: Site hero banner with descriptive alt attribute.

4. TESTING STEPS
1. Add a new news row using add.php.
2. Search for a title (e.g. search "Flood Alert" to verify it matches "City Flood Alert" and excludes "U-17 Final").
3. Open the API URL (http://localhost/daily-city-desk/api/news.php) to confirm valid JSON output.
4. Check the website in two browsers (Google Chrome and Mozilla Firefox or Microsoft Edge).
